## 2026-06-19 - Improved Icon-Only Button Accessibility in Header
**Learning:** Generic icons inside icon-only buttons (`material-symbols-outlined`) must have `aria-hidden="true"` so that screen readers don't announce the visible text of the icon (e.g., "search" or "close") alongside the button's purpose, but rather rely on a descriptive `aria-label` added to the `<button>` element itself. Missing focus rings on close buttons were also a recurrent accessibility pattern found in this app's Header component.
**Action:** Always wrap generic text-based icons in `aria-hidden="true"` and apply a descriptive, translated `aria-label` directly on the parent `<button>`. Ensure focus indicators (`focus-visible:ring-2 focus-visible:ring-primary rounded-[2px]`) are present for keyboard users.
